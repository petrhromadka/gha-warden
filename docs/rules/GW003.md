# GW003: Action not pinned to a full commit SHA

**Severity:** high (medium for actions owned by `actions` or `github`)

## What it detects

A `uses:` reference to an action that is not pinned to a full 40-character
commit SHA. Tags (`@v4`), branches (`@main`) and short SHAs all count as
unpinned. The rule skips local actions (`./path`), self-repository references (`$/path`,
which resolve to the running commit) and `docker://` images that
are pinned by digest. Actions owned by `actions/*` and `github/*` are reported
with medium severity, all other owners with high severity.

## Why it's dangerous

Tags and branches are mutable: whoever controls the action's repository can
move them to a different commit at any time. In March 2025 the
`tj-actions/changed-files` action was compromised and its version tags were
re-pointed to a commit that printed the secrets of every workflow run to the
build log (CVE-2025-30066). Workflows that referenced the action by tag picked
up the malicious code on their next run without any change in their own
repository. A full commit SHA is immutable, so the code you reviewed is the
code that runs. The pin does not protect against a malicious commit that you
pin knowingly, so review the update before you bump the SHA.

## Vulnerable example

```yaml
name: release
on:
  push:
    tags: ["v*"]

permissions:
  contents: write

jobs:
  publish:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v7
        with:
          persist-credentials: false
      - uses: softprops/action-gh-release@v3
```

## Fixed example

```yaml
name: release
on:
  push:
    tags: ["v*"]

permissions:
  contents: write

jobs:
  publish:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@3d3c42e5aac5ba805825da76410c181273ba90b1 # v7.0.1
        with:
          persist-credentials: false
      - uses: softprops/action-gh-release@8a0cd651e5b2365bd640854a3fa5dfc70e4875f3 # v3.0.4
```

Keep the version in a trailing comment so that update tools such as
Dependabot or Renovate can still propose bumps.

## Suppressing

Put the comment on the line the finding points at:

```yaml
      - uses: softprops/action-gh-release@v3  # gha-warden: ignore[GW003]
```

Suppress only for actions whose owner you control and trust as much as your
own repository.
